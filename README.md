# Touchline – Football League and Tournament Management System

**Your Game. Your League.**

## About the Project

Touchline is a web-based Football League and Tournament Management System designed to simplify the organization and management of football competitions. It provides a centralized platform to manage leagues, tournaments, teams, players, fixtures, match results, points tables, and player statistics.

The system helps organizers maintain accurate competition information and allows viewers to follow matches, results, team performance, and league standings.

## Features

- **League Management:** Create and manage football leagues and tournaments.
- **Team Management:** Add teams with their names, logos, and details.
- **Player Management:** Add players and maintain their personal and performance details.
- **Fixture Management:** Create and manage match schedules.
- **Match Results:** Record match scores and match details.
- **Points Table:** Automatically calculate and display league standings.
- **Player Statistics:** Track goals, assists, clean sheets, yellow cards, and red cards.
- **Responsive Design:** Access the platform on desktops, tablets, and mobile devices.

## Project Objectives

- To simplify football league and tournament management.
- To maintain team and player information in one place.
- To manage fixtures and match results efficiently.
- To calculate and display league standings accurately.
- To track player performance and statistics.
- To provide viewers with easy access to football competition information.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone <repository-url>
```

### 2. Open the Project Folder

```bash
cd touchline
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Apply Database Migrations

```bash
python manage.py migrate
```

### 7. Run the Development Server

```bash
python manage.py runserver
```

Open the following URL in your browser:

```text
http://127.0.0.1:8000/
```
